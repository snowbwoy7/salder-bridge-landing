# Salder Bridge Landing Page

Independent client project for a conversion-focused Salder Bridge landing page.

## Current status
Initial scaffold only. This is not production-ready and the inquiry form is not connected to a backend.

## Preserve the existing brand
Use https://salderbridge.com/ as the visual source of truth. Copy the existing logo and the specific brand images/fonts that are approved for reuse into `public/assets/`. Do not create a substitute logo or invent brand colors. Record the actual colors and fonts in `public/css/style.css` only after inspecting the existing site/assets.

## Local preview
You can open `public/index.html` directly for an initial content/layout preview. Later, we will add a local development server and test workflow.

## Next implementation stages
1. Gather/copy existing brand assets and match the current website identity.
2. Refine page content from existing public information and client-approved details.
3. Add an inquiry backend and secure email delivery after the receiving inbox/service is confirmed.
4. Add automated tests, security review, and deployment configuration.
