# Brand assets

Copy the exact approved logo and relevant image assets from the existing https://salderbridge.com/ website into this directory.

- Save the existing logo as `logo.png` or update the image path in `public/index.html` to match the actual file.
- Prefer original assets downloaded from the site's media library over screenshots.
- Reuse existing brand colors, fonts, and imagery; do not invent a replacement identity.
- Before final visual approval, inspect the actual website assets and replace the provisional CSS color tokens with values taken from the existing brand.
- Only use images that the client is authorized to reuse.
